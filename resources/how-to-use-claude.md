# 🤖 How to Use Claude — Your AI Learning Partner

Claude is an AI assistant that can help you learn, write, plan, and build.  
This file gives you **ready-to-use prompts** — just copy, paste, and personalise!

> 🔗 Visit Claude at: https://claude.ai

---

## 🐣 If You're Brand New — Start Here

Copy this and paste it into Claude:

```
Hi Claude! I am completely new to GitHub and technology tools. 
I want to learn GitHub for my career comeback. 
Can you explain what GitHub is using a simple everyday analogy? 
Then tell me the 3 most important things I should learn first.
```

## 💡 Tips for Talking to Claude

- **Be specific** — the more detail you give, the better the answer
- **Say your background** — "I work in finance" or "I'm a teacher" helps Claude tailor its answer
- **Ask follow-up questions** — "Can you make that simpler?" or "Give me an example"
- **Iterate** — "That's good, now make it shorter" or "Add a section about X"
