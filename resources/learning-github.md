# 📖 Learning GitHub — Your Self-Study Guide

This guide helps you keep learning after the session, at your own pace.  
No pressure. No deadlines. Just progress! 🌱

---

## 🗺️ The GitHub Learning Map

Think of GitHub learning in 4 simple stages:

```
Stage 1 → Understand it        (What IS GitHub?)
Stage 2 → Use it               (Create your first repo)
Stage 3 → Show it              (Build your profile)
Stage 4 → Collaborate with it  (Work with others)
```

You don't need to do all 4. Even Stage 2 is enough to get started!

---

## Stage 1: Understand It 🧠

**The key ideas (no jargon!):**

| GitHub Word | What It Really Means |
|---|---|
| **Repository (Repo)** | A project folder that lives online |
| **Commit** | Saving your work with a sticky note explaining what you changed |
| **Branch** | A separate copy of your work where you can experiment safely |
| **Pull Request** | Asking someone to review and approve your changes |
| **Fork** | Taking a copy of someone else's project to build on |
| **README** | The front page / description of your project |
| **Issues** | A to-do list or bug tracker for your project |
| **GitHub Pages** | Turning your repo into a free website |

---

## Stage 2: Use It 🛠️

### Your First 5 Actions on GitHub

- [ ] **1. Create a free account** at https://github.com
- [ ] **2. Create your first repository** — call it `my-first-project`
- [ ] **3. Write a README** — describe yourself or your project in a few sentences
- [ ] **4. Make your first commit** — save your README (this is a big milestone! 🎉)
- [ ] **5. Share your repo link** with someone

> 🎯 **Challenge:** Do all 5 in one sitting. It takes about 20 minutes!

---

## Stage 3: Show It 🌟

### Build Your GitHub Profile

Your GitHub profile is like a living CV. Here's how to make it shine:

- [ ] Add a **profile picture**
- [ ] Write a **bio** (one sentence: who you are, what you do)
- [ ] Add your **location** and **LinkedIn** link
- [ ] Create a **profile README** — this appears on your homepage  
  *(GitHub auto-detects it if you create a repo with the same name as your username)*
- [ ] **Pin your best repositories** so visitors see them first

### GitHub Pages — Your Free Website

Turn any repository into a website in 3 clicks:
1. Open your repository
2. Go to **Settings → Pages**
3. Choose your branch and click **Save**

Your website will be live at: `https://yourusername.github.io`

---

## Stage 4: Collaborate With It 🤝

Once you're comfortable, explore these:

- **Star repositories** you like (like bookmarking)
- **Follow people** in your field
- **Fork a project** and add your own version
- **Contribute to open source** — even fixing a typo counts!
- **Use Issues** to track tasks on your own projects
