# 📚 Teaching — GitHub Resources

GitHub ideas and resources for educators making a career comeback.

---

## 💡 What Can You Put on GitHub as a Teacher?

- Lesson plans organised by subject and year group
- Course syllabi and curriculum maps
- Student resource collections
- Teaching methodology notes
- Open educational resources you've created
- A teaching portfolio in GitHub Pages

---

## 🌟 Project Ideas for Your GitHub Profile

### Beginner
- A repository of your best lesson plans
- A reading list for students with links and notes
- A collection of classroom activity ideas

### Intermediate
- A full course repository (syllabus + weekly lessons + resources)
- A GitHub Pages teaching portfolio website
- An open textbook or study guide

---

## 🤖 Claude Prompt for Teachers

```
I am a teacher returning to the workforce. 
I want to create a GitHub repository to showcase my teaching materials. 
Help me write a professional README and suggest a folder structure 
for a repository containing lesson plans, worksheets, and resources 
for [your subject] at [your level].
```
