# ✅ Getting Started Checklist

Your post-session action plan. Tick these off one by one! 🌟

---

## 🟢 This Week (Quick Wins)

- [ ] Bookmark this repo link so you can find it anytime
- [ ] Create your free GitHub account at https://github.com
- [ ] Create your first repository — name it anything you like!
- [ ] Write a README (even 3 sentences is perfect)
- [ ] Make your first commit — celebrate! 🎉
- [ ] Watch the FreeCodeCamp beginner video (link in `youtube-playlists.md`)

---

## 🔵 In The Next 2 Weeks

- [ ] Complete your GitHub profile (photo, bio, location)
- [ ] Watch the Net Ninja series episodes 1–6
- [ ] Create a second repository related to your career field
- [ ] Explore GitHub's search — find a project in your area of interest
- [ ] Try GitHub Skills (free, interactive): https://skills.github.com

---

## 🟣 Within a Month

- [ ] Set up GitHub Pages and publish a simple website
- [ ] Try using Claude with one of the prompts in `how-to-use-claude.md`
- [ ] Pin your best repositories on your profile
- [ ] Share your GitHub link on LinkedIn 🚀
- [ ] Help another group member with their first repo!
